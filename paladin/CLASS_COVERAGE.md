аудит писался **до** партий 1–11, поэтому в его таблицах стоит `❌` там, где код давно написан

## 5. Диагностика (найти «мёртвые» привязки за один запуск)

Ядро само сообщает о двух самых частых классах ошибок.

### 5.1. Привязка к несуществующему заклинанию
В `Server.log` при старте:
```
Scriptname: `spell_pal_...` spell (Id: NNN) does not exist.
```
Проверьте в `Server.log`: поиск по `does not exist`. Если такие строки есть — пришлите их:
это ровно та ошибка, из-за которой не работало Избавление Тира.

### 5.2. Скрипт, который отключился из-за отсутствующего ID (`Validate`)
```
SpellScriptBase::ValidateSpellInfo: Spell NNN does not exist.
```
Такой скрипт **молча не регистрируется** — механика просто не работает. Поиск по
`ValidateSpellInfo` в `Server.log`.

### 5.3. Привязка к скрипту, которого нет в коде
```
Scriptname: `spell_pal_...` has no code.
```
(осталось от старых партий; в v11 такая одна починена — `spell_pal_crusading_strikes_hp_ex`).
Поиск по `has no code`.

### 5.4. Что у вас в БД
```sql
-- 1) сколько привязок и какие имена (сверяем с 178 именами пакета)
SELECT COUNT(*) AS bindings, COUNT(DISTINCT ScriptName) AS names FROM spell_script_names;

-- 2) привязки, которых нет в коде/которые дублируют старое
SELECT * FROM spell_script_names WHERE ScriptName LIKE 'spell_pal%_ex' OR ScriptName LIKE 'spell_item%_ex';

-- 3) проверка новых механик v10/v11
SELECT * FROM spell_script_names WHERE spell_id IN (402971, 633, 223819, 408458, 200652, 216331, 35395, 20271);
```
Ожидаемо в (3): `402971 → spell_pal_jurisdiction_ex`, `633 → spell_pal_tyrion_guidance_ex`,
`223819/408458 → spell_pal_divine_purpose_buff_ex`, `200652 → spell_pal_tyrs_deliverance_aura_ex`,
`216331 → spell_pal_tyrs_deliverance_aw_ex`, `35395/20271 → spell_pal_avenging_crusader_heal_ex`.

### 5.5. Что присылать по «не работает»
1. строки `Paladin: …` из `Server.log` (все, они по одной на механику за запуск);
2. вывод запроса (2) и (3) выше;
3. вывод поиска по `does not exist` / `ValidateSpellInfo` / `has no code`;
4. что именно нажимали и что увидели (скриншот приветствуется).
