## 8. 🔴 E4 — СИСТЕМНАЯ ОШИБКА БАЗЫ: `SpellFamilyName=10` во всех spell_proc (найдена26.09)

**Симптом:** проки талантов класса молча не срабатывали — без единой ошибки в логе.

**Доказательство (код ядра TC, `SpellInfo::IsAffected`):**
```cpp
if (!familyName) return true;                    // 0 = фильтр выключен (TDB-стандарт)
if (familyName != SpellFamilyName) return false; // 10 (DRUID!) != 2 (PALADIN) -> отсечка
```
У **всех18 наших строк** `spell_proc` стояло `SpellFamilyName=10` (валидное значение
= SPELLFAMILY_DRUID → ядро молча принимало строку, но прок от паладинского спелла
(family=2) отсекался на проверке семейства — для событий типа
`DEAL_MELEE_ABILITY/HELPFUL_SPELL/...`, входящих в `SPELL_PROC_FLAG_MASK`).

**Кто сломан был наверняка** (ProcFlags содержит spell-биты):
`378285` Гнев Тира, `469883` Очищающий огонь, `267316` Мастерство ПВл,
`326732` Сила небес, `406833` Крещендо, `387170` Неземное наследие,
`402912` Праведная причина, `403530` Наказание, `406157` Судья/присяжные/палач,
`157047` Спасение светом (урон-спеллы), `404357` Наставляемая молитва,
`1253174`/`1253598` возврат СС/Крестовый поход, `431474` Второй восход,
`1266308` Резонанс-Рет (если событие CAST проходит через spell-биты).
**Частично работали** (melee-биты не в SPELL-маске): `469309` Око за око,
`406064` Искусство войны. **Под вопросом** (ProcFlags2=CAST_SUCCESSFUL):
`321136` Сияние, `403530`...

**Фикс (этот коммит):**
1. В **репо** все18 строк переписаны: маски=0 → `SpellFamilyName=0` (TDB-стандарт);
   `378285`/`469883` (фам-маски Щита мстителя `[0x4000,0,0x2,0]`) → `SpellFamilyName=2`
   (PALADIN), иначе маски не читаются.
2. Для **живой БД** — `paladin/PROC_FAMILY_FIX.sql` (контроль до/после + UPDATE).

**Что проверить после применения** (функционально): Гнев Тира (Щит → AoE),
Очищающий огонь (Щит → DoT), Сияние (3×СоП → бесплатное Слово), Второй восход
(Молот гнева, шанс15%), Крещендо, Праведная причина, Спасение светом, Око за око —
по §6 и таблице §9.1.
