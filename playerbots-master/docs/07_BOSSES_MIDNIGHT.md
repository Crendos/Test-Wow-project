# v5 — движок босс-механик + контент Midnight (Murder Row)

Боты получают правила поведения на боссах из SQL-таблицы, а не из хардкода:
одна таблица `world.playerbots_boss_rules`, привязка к creature-entry босса.
Движок универсален — новые данжи/рейды добавляются **строчками в SQL, без
перекомпиляции**.

Важное про источник данных: все spell-ID и порядок фаз ниже извлечены из
самих босс-скриптов ядра master (`src/server/scripts/QuelThalas/MurderRow/`),
то есть правила ботов на 100% совпадают с механикой, которая реально
зашита в ядро.

## 2. Движок (`world.playerbots_boss_rules`)

### Триггеры (trigger_type + trigger_arg)
| Триггер | Смысл |
|---|---|
| `boss_cast` | босс сейчас кастует spellId |
| `boss_aura` | на боссе висит аура spellId |
| `bot_aura` | на боте висит аура spellId |
| `hp_below` | HP босса ниже % |
| `always` | всегда в бою (с per-rule кулдауном) |

### Действия (action_type + action_arg)
| Действие | Параметр | Что делает бот |
|---|---|---|
| `interrupt` | — | сбить боссу каст известным interrupt-спелом |
| `run_from_boss` | ярды | отбежать от босса (`MovePoint` относительно позиций — работает на любой арене) |
| `spread` | ярды | отойти от ближайшего союзника |
| `sidestep` | ярды | шаг в случайную сторону (выход из лужи) |
| `switch_target` | creature entry | переключить атаку на add'а; если его нет/он friendly — правило молчит |
| `use_defensive` | — | принудительно сжать защитный кулдаун из книги |
| `dispel_self` | — | диспел с себя известным dispel-спелом (v5: классификатор книги пополнен `SPELL_EFFECT_DISPEL → Kind::Dispel`) |
| `use_burst` | — | принудительно открыть burst-окно на 5с (v4 GCD-движок подхватит) |

Цикл: каждый тик боя правила проверяются по возрастанию `seq`, исполняется
**первое сработавшее** (движущие действия не едят GCD — ротация продолжается).
`cooldown_ms` — антиспам per-правило. Обычное движение/follow замораживается
на время rule-move (`m_ruleMoveBlockMs`), чтобы бот не спорил сам с собой.

Загрузка: при первом обращении к боссу (не при старте мира) — таблица может
отсутствовать, тогда в лог пишется info-строка и механики просто отключены.

## 3. Murder Row → Kystia Manaheart (234648) — расшифровка из ядерного скрипта

Скрипт: `src/server/scripts/QuelThalas/MurderRow/boss_kystia_manaheart.cpp`
(558 строк, BossAI + spells + AreaTrigger).

### Фазы и спелы босса
| Спел | ID | Механика (из кода) |
|---|---|---|
| Fel Crazed | 474365 | с пула на боссе → заменяет эффектом стеки **Felshield (1217989)** ×4 |
| Chaos Barrage | 1230298 | filler по танку каждые 3.5 с — безопасно терпеть |
| Mirror Images | 1264095 | каждые 30.5 с спавнит образов (1264098) в рандомных точках — урон вокруг |
| Fel Nova (heroic+) | 474240 selector → 474183 **Blink** к случайному игроку → 1223906 **FelNova** у его ног | каждые 15 с |
| Illicit Infusion (cast) | 474238 | channel на Nibbles → на выходе: +стеки Felshield, **Nibbles становится hostile** |

### Nibbles (234660) — ключевая механика боя
| Спел | ID | Что происходит |
|---|---|---|
| Illicit Infusion (aura) | 1230289 | «заражён» — hostile, дерётся |
| Fel Spray | 1253811 | кладёт AreaTrigger-лужу (39560): игрок в зоне → FelSprayDamage (**1253813**) |
| Corroding Spittle | 1228198 | random-target дебафф (каждые 14.5 с) |
| CheckHealth (event) | — | HP Nibbles ниже порога из Illicit Infusion eff0 → кукла становится friendly и кастует на босса **Light Infusion (1230304)** → босс получает **Destabilized (1265412) → стун-окно урона** |

### Как из этого сделаны правила ботов (sql/world_playerbots_boss_rules.sql)
| seq | Триггер → Действие | Логика |
|---|---|---|
| 10 | boss_cast 474183 → run_from_boss 12y | Нова взрывается вокруг босса после блинка — уйти |
| 20 | boss_aura 1217989 → switch_target 234660 | Пока у босса щит и Nibbles hostile — бить Nibbles (выбить в нём Destabilized). До превращения Nibbles friendly — правило само молчит |
| 30 | boss_aura 1265412 → use_burst | Босс в стане — жечь кулдауны |
| 40 | boss_aura 1264095 → spread 8y | Образы — фоновый урон вокруг, не толпиться |
| 50 | bot_aura 1253813 → sidestep 8y | Стоим в fel-луке — выйти |
| 60 | bot_aura 1228198 → dispel_self | Плевок — снять, если умеем (книга Kind::Dispel) |

Смотри-вывод в игре: боты дают боссу пачку дота/нюков в окне пула → как только
Nibbles загнали hostile, переключаются на него → босс в стан → бурствуют →
«blink» — резко отбегают → возвращаются.

## 4. Процесс добавления новых боссов (манифест на будущее)

1. Дождаться босс-скрипта в master (или готового порта).
2. Из скрипта извлечь: boss entry, `Spells::` enum (ID), `events.ScheduleEvent/Repeat` (тайминги), selector'ы бликов/луг, `OnUnitEnter` аурек AreaTrigger'ов.
3. Письменная табличка «спел → что должен делать живой игрок».
4. Перевести в строки `playerbots_boss_rules`. Движение всегда относительное
   (никаких фиксированных координат) — устойчиво к любой геометрии арены.
5. `REPLACE INTO` → `.reload` не нужно: правила грузятся при первом входе в бой
   с боссом после старта мира (перезапуск worldserver).
