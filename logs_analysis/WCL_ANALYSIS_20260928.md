# Сверка с логами WCL, 28.09.2026 (v4, `PAL_REV4_20260928`)

Исходные CSV: ветка `main`, папка `logs_analysis/wcl logs/Paladin/` (6 спек+древо, топ М+ 12.1, ключи 18–22).
Игроки одеты (экипировка, камни, чары, аксессуары, сетовые бонусы) — поэтому абсолютные цифры урона/лечения
**не** сравниваются с сервером. Сверяется *структура*: число попаданий на каст, какие отдельные спеллы
появляются в логе, частота/аптайм аур. Предметные эффекты (Venomfang, Omnium Folio, руны, Unrelenting Edict,
Voracious Heart, Soulcoiler и т. п.) — это экипировка, к классу не относятся.

WCL в CSV группирует спеллы по имени: первая строка группы — сумма, дальше составляющие.
