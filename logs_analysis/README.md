## Авангард — шанс
77 проков. При 20%: нужно 385 кастов Правосудия = 1 каст / 4.5 с активного боя — типичный темп Прот в М+
(КД 6 с + заряды «Праведного суда»/сбросы). **Данные согласуются с хардкодом 20% (simc) — оставляем.**

## Доблесть — открытый вопрос
211 приложений против 77 у Авангарда. В нашей реализации (партия 7) Доблесть даётся ТОЛЬКО при потреблении
Авангарда Щитом мстителя (ранк 3 Славы авангарда, по simc). 211 stack-гейнов намекают, что в рознице
Доблесть копится чаще (возможно, +1 за каждый тратящий СС / за ЩП). Для вердикта нужна выгрузка «Касты»
(Правосудие, Щит мстителя, Щит праведника): Доблесть ≈ кастам ЩП → источник ЩП; ≈ кастам ЩМ → источник ЩМ.

## Авангард — шанс (финальная проверка по «Кастам»)
Правосудие: **349 кастов**, Авангард: **77 проков** → **22.1%**. При 20% матожидание 69.8 (σ≈7.5) —
отклонение +0.96σ. **Шанс 20% подтверждён, правки не требуются.**

## Доблесть — предупреждение о contamination
CSV «Бафы» агрегирован по ВСЕМ игрокам рейда (в списке бафы ДК/ДХ/вара). «Доблесть» 211 приложений
может содержать чужие бафы — для вердикта нужна выгрузка с фильтром Source = паладин.
Правила Доблести по simc: стакается (20 с), выдаётся болтом Славы авангарда, тратится ЩП целиком
(до 5 стаков), +E1% урона ЩП за стак (основная цель).

## Уточнения партии 7 по simc (внесены после разбора лога)
- болт летит **через 300 мс после попадания** Щита мстителя (было мгновенно);
- **в АН Авангард не тратится** (болт летит, Авангард остаётся до ЩМ вне АН);
- **Blaze of Glory бьёт и основную цель** ЩП (+ до 4 вторичных, было только 4 вторичных).

## Чего не хватает (для точных цифр)
Выгрузка «Касты» с фильтром Source = паладин: строки Правосудие / Щит мстителя / Щит праведника / Молот праведника.
Формула шанса Авангарда: `Count(Авангард) ÷ Casts(Правосудие)` = 77 ÷ N.
